Custom hooks: connection and subscriptions
Own the connection lifecycle

useRelay(connect, handlers)

Shared by the monitor and control room. An effect creates the connection and cleanup disposes it. The connection layer handles transport and reconnection.

  • useState exposes connection status; useRef holds the connection object.
  • useEffect performs setup and cleanup; connect must have a stable identity.
  • useEffectEvent reads current handlers without reconnecting on each render.
  • useCallback supplies a stable send function.
Subscribe to readings

useReadings / useLatestReading

Both wrap useSyncExternalStore. One exposes the whole rolling window; the other exposes the newest sample. A snapshot keeps its reference until the underlying data changes.

  • The same readings store supplies the chart and readout.
  • Subscription cleanup removes the listener on unmount.
  • useAppDispatch and useAppSelector are separate, typed React Redux hooks.
Supporting React boundaries: cleanup, loading, and failures

StrictMode checks cleanup

In development, the browser apps exercise an extra effect setup/cleanup cycle. Disposing the owned connection closes its socket and cancels retries. Setup → cleanup → setup must be safe.

Load and fail in small boundaries

The monitor lazy-loads the chart with a Suspense fallback. Root and panel Error Boundaries isolate render failures. Event-handler and asynchronous errors still need explicit handling.
